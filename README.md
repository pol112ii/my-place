# 나만의 장소 (My Place)

다녀온 곳 중 **인상 깊었던 장소**를 지도에 별표로 찍고, 별점과 짧은 메모를 남기는 개인 기록장입니다.

계정도, 서버도, 로그인도 없습니다. 기록은 **내 브라우저 안에만** 저장됩니다.

## 할 수 있는 것

| | |
|---|---|
| 📍 **지도에 별표** | 지도를 눌러 그 자리에 장소를 추가합니다. 핀을 끌어서 위치를 미세 조정할 수 있어요. |
| ⭐ **별점 1~5** | 얼마나 좋았는지 별로 남깁니다. 별점은 지도 핀 안에 숫자로 보입니다. |
| ★ **즐겨찾기** | 특히 다시 가고 싶은 곳은 별표를 켜 두면 금색 핀이 되고, `★ 즐겨찾기` 필터로 모아 볼 수 있습니다. |
| 📝 **메모** | 무엇이 좋았는지, 누구와 갔는지 자유롭게. 목록 카드에 바로 보입니다. |
| 🗂 **지역별 묶어보기** | 목록이 `노원구` `방이동` `포항시`처럼 지역으로 묶여 나옵니다. 소제목은 스크롤해도 위에 붙어 있습니다. |
| 🏷 **태그** | `카페, 산책, 제주`처럼 쉼표로 구분해 넣고 태그별로 걸러 봅니다. |
| 🔎 **검색·정렬** | 이름·메모·주소·태그를 한 번에 검색. 지역별 / 방문일 / 별점 / 최근 기록 / 이름 순. |
| 🔍 **이름·주소로 찾기** | 장소 이름이나 주소를 넣고 `찾기`를 누르면 좌표·주소·지역이 자동으로 채워집니다. |
| 🧭 **지도앱으로 열기** | 기록한 곳을 구글지도·애플지도에서 바로 열거나 길찾기를 시작합니다. |
| 💾 **백업** | `⋯` 메뉴에서 `.json` 파일로 내보내고, 다른 기기에서 가져올 수 있습니다. |
| 🌙 **밝기** | 시스템 설정 / 밝은 화면 / 어두운 화면을 버튼으로 전환합니다. |
| ✈️ **오프라인** | 앱 파일을 저장해 두어 인터넷이 없어도 기록을 열어 볼 수 있습니다(지도 타일만 안 보입니다). |

## 시작하기

**1. 그냥 열어 보기**

`index.html`을 브라우저로 열면 바로 동작합니다. (이 방식에서는 홈 화면 앱 설치와 오프라인 기능만 빠집니다.)

**2. 내 주소로 올려 두기 — GitHub Pages**

이 저장소의 `Settings → Pages`에서 `Source: Deploy from a branch`, 브랜치는 이 브랜치(또는 `main`), 폴더는 `/ (root)`로 저장하면
`https://<내아이디>.github.io/my-place/` 주소로 열립니다. 저장소를 **Private**으로 두면 주소를 아는 사람만 들어올 수 있습니다.

> 참고: GitHub Pages는 저장소가 비공개여도 페이지 자체는 공개될 수 있습니다. 완전히 나만 보려면 1번(파일로 열기)이나
> 집 안의 개인 서버에 올리는 방법이 가장 확실합니다. 어느 쪽이든 **기록 내용은 어디에도 업로드되지 않습니다.**

**3. 휴대폰 앱처럼 쓰기**

위 주소를 휴대폰에서 연 뒤
- 아이폰: 공유 → `홈 화면에 추가`
- 안드로이드: 메뉴 → `앱 설치` / `홈 화면에 추가`

주소창 없는 전체 화면으로 열리고, 비행기 모드에서도 기록을 볼 수 있습니다.

## 휴대폰에 맞춰 둔 것

- **노치·다이내믹 아일랜드 비켜 가기** — `env(safe-area-inset-*)`으로 위아래를 비워 둡니다. 아이폰 15 Pro(393×852, 위 59pt·아래 34pt) 기준으로 맞춰 확인했습니다.
- **손가락 크기 버튼** — 별점·별표·탭·버튼을 모두 40px 이상으로 잡았습니다.
- **확대 안 되는 입력칸** — 입력 글자를 16px로 두어 iOS가 초점 맞출 때 화면을 확대하지 않습니다.
- **아래에서 올라오는 입력창** — 손잡이를 아래로 끌어 닫을 수 있고, 키보드가 올라와도 가려지지 않습니다.
- **한 화면에 하나씩** — 아래 `지도` / `목록` 탭으로 전환합니다. 필터 줄은 옆으로 넘겨 볼 수 있습니다.

## 쓰는 법

1. 지도에서 다녀온 자리를 누릅니다. (또는 `＋ 장소 추가` 버튼)
2. 이름을 적고 별점을 누릅니다. 같은 별을 다시 누르면 별점이 해제됩니다.
3. 메모와 태그를 남기고 `저장`.
4. 목록에서 카드를 누르면 지도가 그 장소로 이동하고, `편집`으로 언제든 고치거나 지울 수 있습니다.

### 지역은 어떻게 정해지나요

주소에서 자동으로 뽑되, **직접 고칠 수 있습니다.** 지역 칸 아래에 후보가 나오니 원하는 단위를 누르면 됩니다.

| 주소 | 자동으로 잡히는 지역 | 고를 수 있는 후보 |
|---|---|---|
| 서울특별시 송파구 방이동 | `송파구` | 방이동 · 송파구 · 서울 |
| 서울특별시 노원구 상계동 | `노원구` | 상계동 · 노원구 · 서울 |
| 경상북도 포항시 북구 죽도동 | `포항시` | 죽도동 · 북구 · 포항시 · 경북 |

특별시·광역시는 `구`가, 그 밖에는 `시·군`이 기본값입니다. `북구`처럼 여러 도시에 있는 이름보다
`포항시`가 혼자서도 어디인지 알 수 있기 때문입니다. 주소가 없는 기록은 `지역 없음`으로 묶입니다.

지역 이름을 손으로 적어도 됩니다. `제주 3일차`, `퇴근길`처럼 마음대로 묶어도 그대로 동작합니다.

## 내 기록은 어디에 있나요

기록은 브라우저의 `localStorage`(키: `myplace.v1`)에 저장됩니다. 외부로 보내는 서버가 없습니다.

그래서 이런 점만 기억해 두세요.

- **기기마다 따로입니다.** 폰에서 쓴 기록이 노트북에 자동으로 오지 않습니다 → `백업 내보내기` 후 다른 기기에서 `백업 가져오기`.
- **브라우저 데이터를 지우면 함께 사라집니다.** 가끔 백업을 내려받아 두세요.
- 가져오기는 **합치기**로 동작합니다(같은 기록은 새 것으로 덮어씀). 통째로 바꾸려면 `전체 삭제` 후 가져오면 됩니다.
- 사생활 보호 모드 등으로 저장이 막혀 있으면 앱이 알려 주고, 그때는 창을 닫을 때까지만 유지됩니다.

### 밖으로 나가는 요청

기록 내용은 나가지 않지만, 지도를 쓰는 이상 아래 두 가지는 OpenStreetMap 서버로 갑니다.

- **지도 타일** — 지금 보고 있는 지도 영역의 좌표
- **이름·주소로 찾기 / 주소 자동 채우기** — 입력한 검색어 또는 찍은 좌표 ([Nominatim](https://nominatim.org))
- **지도앱으로 열기** — 눌렀을 때만, 해당 장소의 좌표가 구글지도·애플지도 주소에 담겨 열립니다

메모·별점·태그·목록은 어떤 경우에도 전송되지 않습니다. 이마저도 피하려면 지도를 쓰지 않고 목록만 써도 됩니다.

## 파일 구조

```
index.html                 화면 뼈대
manifest.json              홈 화면 앱 설정
sw.js                      오프라인용 서비스 워커
assets/css/style.css       스타일 (밝은/어두운 화면 토큰)
assets/js/region.js        주소에서 지역 이름 뽑기
assets/js/store.js         저장·불러오기·백업
assets/js/geocode.js       장소·주소 ↔ 좌표 변환
assets/js/mapview.js       지도(Leaflet) 처리
assets/js/app.js           화면 구성과 조작
assets/vendor/leaflet/     지도 라이브러리 (CDN 없이 직접 포함)
assets/icons/              앱 아이콘
```

빌드 도구나 설치 과정이 없습니다. 파일을 고치고 새로고침하면 끝입니다.
